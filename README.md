# java-lru-cache

A custom implementation of a Least Recently Used (LRU) cache in Java, using a Doubly Linked List and a HashMap for O(1) operations.

## Usage
Compile and run:
```bash
javac -d bin src/com/toy/*.java
java -cp bin com.toy.Main
```
